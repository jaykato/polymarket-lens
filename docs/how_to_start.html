Polymarket Lens · v0.6.1

使用方法

Polymarketの公開APIを使う、読み取り専用のローカル分析アプリです。 ウォレット、秘密鍵、APIキーは使いません。売買機能もありません。

動作環境

項目 必要なもの
Python 3.10以上。入っていない場合は python.org から入れ、 インストール時に「Add python.exe to PATH」に必ずチェックを入れてください
追加パッケージ 不要。標準ライブラリだけで動きます。pip installも仮想環境も要りません
OS Windows 11でのみ動作確認しています。 macOS・Linuxは未検証です。start_app.batとsync_data.batは Windows専用のため、他のOSでは「7. コマンドで操作する」の方法を使ってください
画面 960 × 540ピクセル以上のウィンドウ。スマートフォンは非対応です
ブラウザ 最近のものであれば種類は問いません。画面はブラウザ上に表示されます
ネット接続 データ取得時のみ必要です。取得済みのデータを見るだけならオフラインでも動きます

Pythonが見つからない場合、start_app.batはその旨を表示して停止します。 画面の案内どおりPythonを入れてから、もう一度実行してください。

1. 起動する

  1. start_app.bat をダブルクリック

    ダウンロードした polymarket-lens フォルダの直下にあります。黒い画面が開きます。

  2. 初回だけ、データ取得を待つ

    data\polymarket.db がまだ無い場合、公開APIから25市場を取得して SQLiteへ保存します。2回目以降はこの待ち時間はありません。

  3. ブラウザが自動で開く

    開かない場合は http://127.0.0.1:8765 を手で開いてください。

  4. 終了するときは黒い画面で Ctrl+C

    ブラウザのタブを閉じただけではサーバーは止まりません。

表示には960 × 540ピクセル以上のウィンドウが必要です

これを下回るサイズ、およびスマートフォンでは、画面を表示せず案内だけが出ます。 左右2ペインの構成を保つための制限です。ウィンドウを広げるか、PCで開いてください。

2. 市場を探す

Search

検索

質問文、説明文、slug（URLの断片）を対象に検索します。 保存済みデータに該当が無いキーワードは、Polymarketの公開検索へ自動で問い合わせ、 見つかった市場をDBへ保存します。

Sort

並べ替え

出来高、流動性、終了日（近い順）、スプレッド（狭い順）の4通りです。 既定は出来高順です。

Filter

薄い市場を隠す

「Hide thin markets」で流動性 $1,000 未満の市場を除きます。 板が薄い市場は、表示価格どおりに約定しない可能性が高くなります。

3. チャートを読む

市場をクリックすると右側に詳細が出ます。チャートはYES確率の推移です。

期間 解像度 用途
1D5分刻み直近1日の細かい動きを見る
1W1時間刻み既定。1週間の流れを見る
1M3時間刻み1ヶ月のトレンドを見る
MAX12時間刻み市場が始まってからの全体像を見る
Axis

縦軸は常に0〜100%

データの範囲に合わせた自動拡大はしません。拡大すると、わずかな変動が 大きな動きに見えてしまうためです。

Axis

横軸は実時刻

観測点の順番ではなく実際の時刻で描きます。データが飛んでいる区間は、 そのまま横に間延びして見えます。

Hover

カーソルを重ねる

その時点のYES確率と日時が出ます。チャート右上には、選択中の期間での 変動幅がポイント単位で表示されます。

1Dを見たあと1Wに戻すと、右端だけ点が密になります

取得した観測値をすべて同じ場所に貯めているためです。補間も間引きもしておらず、 どの点も実際に記録された値です。表示が細かくなるだけで、形は正しいままです。

4. 価格変動サマリーを読む

チャートの下に、選択中の期間について観測された事実だけが並びます。 追加のAPI呼び出しはせず、保存済みの履歴だけから計算しています。

項目 意味
Change over range期間の最初から最後までの変動幅
Change, last 24h直近24時間の変動幅。期間が24時間に満たない場合は出ません
Range high / low期間内の高値・安値と、その時刻
High to low高値と安値の差
Typical daily swing1日あたりの典型的な変動幅
Largest single move隣り合う観測点の間で最も大きかった変動と、その所要時間
表示 意味
Steady日々の動きが小さい
Active日々はっきり動いている
Volatile日々の振れが大きく、表示確率が安定しない

この3段階は動きの大きさだけを表します。値動きの大小に良し悪しはないため、 次の「市場コンディション」とは別の配色にしています。

5. 市場コンディションを読む

スプレッド、流動性、累積出来高から、その市場での売買のしやすさを評価します。 YESとNOのどちらが当たるかの予測ではありません。

色 意味
緑比較的良好な取引環境
黄価格または流動性に注意
ピンク高コスト・低流動性の可能性
「良好」は「儲かりやすい」ではありません

表示価格と実際の約定価格の差が比較的小さく、ポジションを出入りしやすい可能性を示すだけです。 「Crowd leans YES / NO」も、現在価格が示す市場参加者の傾きを説明するもので、 このアプリ独自の予測ではありません。

6. データを更新する

Manual

sync_data.bat

ダブルクリックすると、出来高上位50市場の情報、価格履歴、注文板を取り直します。 アプリを起動したままでも実行できます。更新後はブラウザを再読み込みしてください。

Automatic

チャートの自動更新

チャートの期間を切り替えたとき、その期間を最後に取得してから15分以上経っていれば 自動で取り直します。15分以内なら保存済みデータをそのまま表示します。

7. コマンドで操作する

コマンドラインから直接実行する場合です。Python 3.10以上が必要です。 Windowsの公式インストーラを使った場合は py -3 でも実行できます。 

cd <アプリを置いたフォルダ>

# データベースを初期化する
python -m polymarket_app init

# 50市場を取得する
python -m polymarket_app sync --markets 50

# 保存件数を確認する
python -m polymarket_app stats

# Web UIを起動する
python -m polymarket_app serve
コマンド オプション 説明
init — DBを作る。既存データは消えません
sync --markets N 取得する市場数。既定は25
--histories N 履歴を取る市場数の上限。省略時は全市場
stats — market数、outcome数、価格点数、最終同期時刻
serve --port N 待ち受けポート。既定は8765
--host H 既定は127.0.0.1。このPCからのみ接続できます
--db PATH 全コマンド共通。既定はdata\polymarket.db

8. 困ったとき

Error

ブラウザに何も出ない

黒い画面が閉じていないか確認してください。閉じているとサーバーが止まっています。 start_app.bat をもう一度実行します。

Error

初回の同期に失敗する

インターネット接続を確認してから、もう一度実行してください。 Polymarket側が一時的に応答しない場合もあります。

Error

ポート8765が使えない

別のアプリが使っている可能性があります。 serve --port 8790 のように変更し、その番号でブラウザを開いてください。

Error

チャートに履歴が出ない

注文板が有効でない市場には価格履歴がありません。 「No price history for this range.」と表示されます。

Reset

データを作り直したい

data フォルダを削除してから start_app.bat を実行すると、 最初から取得し直します。

Test

動作を確認したい

テストはネット接続なしで実行できます。 

python -m unittest discover

注意事項

研究用ツールであり、投資助言ではありません

このアプリは公開データを表示するだけです。売買の実行、ウォレット接続、賭けの推奨、 地域制限の回避機能はありません。HTTPメソッドはGETのみを使い、注文の作成・取消は 実装していません。サーバーは既定で 127.0.0.1 にのみ接続を受け付けます。 Polymarketの利用可否と適用法令は地域により異なります。
