Polymarket Lens · v0.6.1

How to use

A read-only local viewer for public Polymarket data. It uses no wallet, no private key, and no API key, and it cannot place a trade.

Requirements

Item What you need
Python 3.10 or newer. If it is not installed, get it from python.org and be sure to tick Add python.exe to PATH during setup
Packages None. The application runs on the standard library alone. There is no pip install step and no virtual environment
Operating system Tested on Windows 11 only. macOS and Linux are unverified. start_app.bat and sync_data.bat are Windows-only, so on other systems use the commands in section 7
Display A window of at least 960 × 540 pixels. Phones are not supported
Browser Any recent one. The interface is served to your browser
Network Needed only while fetching data. Reading what is already stored works offline

If Python is missing, start_app.bat says so and stops. Install Python as the message describes, then run it again.

1. Start it

  1. Double-click start_app.bat

    It sits at the top of the polymarket-lens folder you downloaded. A console window opens.

  2. Wait for the first download

    If data\polymarket.db does not exist yet, 25 markets are fetched from the public API and written to SQLite. Later runs skip this wait.

  3. Your browser opens

    If it does not, open http://127.0.0.1:8765 yourself.

  4. To stop, press Ctrl+C in the console window

    Closing the browser tab does not stop the server.

The interface needs a window of at least 960 × 540 pixels

Below that size, and on phones, it shows a notice instead of the layout. The limit exists to keep the two-pane structure intact. Widen the window, or open it on a desktop machine.

2. Find a market

Search

Search

Searches the question text, the description, and the slug. If a keyword matches nothing in your local database, Polymarket's public search is queried instead and whatever it returns is saved.

Sort

Sort

By volume, liquidity, end date (soonest first), or spread (tightest first). Volume is the default.

Filter

Hide thin markets

Hide thin markets drops anything under $1,000 of liquidity. In a thin book, your order is more likely to fill away from the displayed price.

3. Read the chart

Click a market and its detail appears on the right. The chart is the YES probability over time.

Range Resolution Use it for
1D5 minutesFine detail over the past day
1W1 hourThe default. The shape of the past week
1M3 hoursA month-long trend
MAX12 hoursEverything since the market opened
Axis

The vertical axis is always 0–100%

It never zooms to fit the data. Zooming makes a small move look like a large one.

Axis

The horizontal axis is real time

Points are plotted at the time they were recorded, not by their position in the series. Where observation stopped, the line stretches across the gap.

Hover

Hover over a point

The YES probability and the timestamp appear. The top right of the chart shows the change across the selected range, in points.

After viewing 1D, the right-hand edge of 1W looks denser

Every observation is stored in the same place, whichever range fetched it. Nothing is interpolated and nothing is thinned out — every point is a value that was actually recorded. Only the density of the drawing changes; the shape stays true.

4. Read the movement summary

Below the chart is what was observed over the selected range, and nothing more. It is computed from stored history, with no extra API calls.

Item Meaning
Change over rangeFirst to last point of the range
Change, last 24hThe past 24 hours. Hidden when the range is shorter than that
Range high / lowThe highest and lowest points, and when each occurred
High to lowThe distance between them
Typical daily swingHow far the probability moves in an ordinary day
Largest single moveThe biggest step between two adjacent observations, and how long it took
Label Meaning
SteadyDay-to-day movement is small
ActiveIt moves clearly from day to day
VolatileDaily swings are wide; the displayed probability is unsettled

These three describe the size of the movement only. A large move is neither good nor bad, which is why they use a different palette from the market conditions below.

5. Read market conditions

Spread, liquidity, and cumulative volume, combined into a read on how expensive this market is to enter and leave. It is not a forecast of whether YES or NO will resolve.

Colour Meaning
GreenRelatively good trading conditions
YellowWatch the price or the liquidity
PinkPossibly expensive, possibly illiquid
"Good" does not mean "profitable"

It says only that the gap between the displayed price and the price you would actually get is relatively small, so a position is easier to open and close. Crowd leans YES / NO likewise describes where the current price puts the participants — it is not a prediction of this application's own.

6. Refresh the data

Manual

sync_data.bat

Double-click it to re-fetch the top 50 markets by volume, their price history, and their order books. It can run while the application is up. Reload the browser afterwards.

Automatic

The chart refreshes itself

When you switch chart ranges, that range is re-fetched if more than 15 minutes have passed since it was last retrieved. Within 15 minutes, stored data is shown as is.

7. Use the command line

For running the application directly. Python 3.10 or newer is required. If you installed Python with the official Windows installer, py -3 works too. 

cd <the folder you put the application in>

# Create the database
python -m polymarket_app init

# Fetch 50 markets
python -m polymarket_app sync --markets 50

# Show what is stored
python -m polymarket_app stats

# Start the web interface
python -m polymarket_app serve
Command Option Description
init — Create the database. Existing data is preserved
sync --markets N Number of markets to fetch. Default 25
--histories N Cap on markets to pull history for. Omitted means all
stats — Market, outcome, and price-point counts, and the last sync time
serve --port N Listening port. Default 8765
--host H Default 127.0.0.1, reachable only from this machine
--db PATH Available on every command. Default data\polymarket.db

8. Troubleshooting

Error

The browser shows nothing

Check whether the console window is still open. If it closed, the server stopped. Run start_app.bat again.

Error

The first sync fails

Check your internet connection and try again. Polymarket's own endpoints are sometimes temporarily unavailable.

Error

Port 8765 is unavailable

Another application may be holding it. Use something like serve --port 8790 and open that port in your browser.

Error

The chart has no history

Markets without an active order book have no price history. You will see No price history for this range.

Reset

Start the data over

Delete the data folder, then run start_app.bat. Everything is fetched again from scratch.

Test

Check that it works

The tests run without a network connection. 

python -m unittest discover

Scope and limits

A research tool, not investment advice

This application displays public data and nothing else. It cannot execute a trade, connect a wallet, recommend a position, or circumvent a regional restriction. It issues only GET requests, and order creation and cancellation are not implemented. The server accepts connections on 127.0.0.1 alone by default. Whether Polymarket may be used, and which laws apply, differ by jurisdiction.
